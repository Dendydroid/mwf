Quick reference

Models used

Every model the assistant depends on: what kind of model it is, how large it is and where it runs. Two neural models are self-hosted. The browser's speech models are used only by the mimic client.

INTENT_MATCHER=llm (default)

Qwen2.5 runs both machines: machine #1 (intent matcher) and machine #2 (response formulator). Only the GPU is used.

INTENT_MATCHER=classifier

GLiNER2 and Lingua run machine #1 on the CPU, and Qwen2.5 still writes every reply as machine #2. The classifier container always starts, whichever mode is set.

Good to know

  • Weights download on first start into LLM_CACHE_DIR, which both containers mount. Later starts are offline.
  • Any model vLLM supports can replace Qwen2.5 through LLM_MODEL. Keep it instruction-tuned and multilingual, because both machines rely on it.
  • dateparser, which turns “the 15th of June” into a date in classifier mode, is rule-based, not a model.
